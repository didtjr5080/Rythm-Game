## 측정 순서

1. Settings에서 원하는 신호 종류를 선택하고 Connect / Test EMG를 누릅니다.
2. 1번 안정 측정: 약 4초간 힘을 뺍니다. 처음 0.75초를 제외하고 3초를 수집합니다.
3. 2번 3회 반복 수축: 약 12초간 화면을 보고 **힘빼기 2초 → 힘주기 2초**를 3회 반복합니다. 12초 내내 계속 힘을 주면 이완 구간이 분리되지 않아 실패합니다.
4. 각 2초 구간의 처음 0.5초는 전환/평활화 정착 시간으로 제외합니다. 나머지 실제 수신 표본을 구간별로 저장합니다. UI 반복 조회는 표본으로 세지 않습니다.
5. 성공 시 ON/OFF와 3회 수축 중앙값을 확인하고 Save를 누릅니다. 실패하면 안정 P95·흔들림·수축별 P10·최약 차이가 표시됩니다.

EXTRACTED: 초기 안정 측정은 최소 60표본, 각 반복의 이완/수축 구간은 각각 최소 30표본이 필요합니다. 연결 끊김·소스 변경·화면 종료 시 기존 취소 처리를 유지합니다. 실패 시 이전 ON/OFF는 덮어쓰지 않습니다.

## 판정 계산

EXTRACTED: `app/input/emg_processing.py`는 초기 안정 구간과 반복 중 이완 3구간을 따로 검사합니다. 각 구간의 중앙값 기준 MAD와 P95–P05 범위를 사용합니다. 백분위수는 정렬한 표본의 내림 인덱스입니다.

```text
각 이완 구간의 spread = max(1.4826 × MAD, (P95 − P05) / 3.29)
흔들림 = 모든 이완 구간 spread의 최댓값
안정 상한 = 초기 안정/이완 3구간 P95 중 최댓값
최약 수축 = 수축 3구간 P10 중 최솟값
분리 차이 = 최약 수축 − 안정 상한
```

EXTRACTED: 차이가 양수이고 흔들림의 2배 이상이어야 합니다. 모든 반복의 수축 하위값이 모든 이완 구간의 상위값보다 높아야 하므로 한 번만 튀거나 한 번의 약한 수축이 겹치는 경우도 거부합니다. 최악 구간을 사용하므로 이완 기준이 도중에 상승하는 경우도 단순 평균으로 숨기지 않습니다.

```text
ON  = 안정 상한 + 분리 차이 × 0.60
OFF = 안정 상한 + 분리 차이 × 0.20
```

EXTRACTED: ON/OFF는 소수점 셋째 자리로 계산합니다. 반올림 후에도 안정 상한 < OFF < ON < 최약 수축이어야 하며 ON 1000 이하 조건을 유지합니다. 표본 부족, 비유한·음수·1020 이상 활동값은 계속 거부합니다. 소수점 0.001의 표현 정밀도로 경계가 구분되지 않는 극소 차이도 거부합니다.

EXTRACTED: 안정 8.4, 수축 3회가 모두 11.7이고 각 이완도 8.4로 일정한 합성 예시는 차이 3.3이어도 ON 10.380/OFF 9.060으로 통과합니다. 같은 정도의 차이라도 이완 흔들림이 크면 실패합니다. 이 예시는 사용자의 실제 신호 측정 결과가 아닙니다.

INFERRED: 계수 2와 백분위수 기반 규칙은 소프트웨어의 보수적인 분리 기준입니다. 연속 표본은 상관관계가 있으므로 이를 독립 표본의 통계 검정이나 특정 신뢰도로 해석하지 않습니다. 실제 착용 상태의 오입력률과 누락률은 별도 확인해야 합니다.
