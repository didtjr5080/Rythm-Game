# 5레인과 EMG 입력

EXTRACTED: 손가락 종류에 관계없이 펼친 전체 개수가 레인 번호입니다. 1~5개는 각각 1~5번 레인을 선택합니다. 주먹과 손 미검출은 레인을 선택하지 않으며, 손의 가로 위치로 대체하지 않습니다.

EXTRACTED: 실제 센서 모드에서 장치 미연결·통신 오류·신호 중단은 입력을 차단합니다. SPACE는 설정에서 명시적으로 선택한 모의 입력 모드에서만 동작합니다. 최근 샘플이 150ms 이상 없으면 활성 상태를 반환하지 않습니다.

EXTRACTED: 센서는 임계값 60% 미만의 휴식 샘플 4개를 받은 뒤 준비됩니다. 임계값 이상의 연속 샘플 2개가 수축을 활성화합니다. 한 번의 수축은 최대 한 노트만 판정하며, 다음 판정에는 휴식 후 재수축이 필요합니다. 임계값 0은 입력을 활성화하지 않습니다.

EXTRACTED: 새 채보에는 `lane_count: 5`가 저장됩니다. 기존 3레인 채보는 1·3·5번 레인으로 확장해 기존 좌우 배치를 유지합니다. 카메라가 없을 때 숫자키 1~5로 레인을 선택할 수 있습니다.

검증: `WorkOrder/verify_emg_serial.py`, `WorkOrder/verify_fingers.py`, `WorkOrder/verify_five_lane_input.py`. 실제 착용 상태의 휴식 잡음과 수축 신호에 맞는 임계값 조정은 별도 확인이 필요합니다.
