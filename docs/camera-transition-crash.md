# 손 클릭 후 설정 화면 전환 크래시

EXTRACTED: 2026-11-09 Windows 오류 기록에서 v2026.11.09.2 실행 파일의 `0xc0000005` 종료 두 건을 확인했습니다. 두 덤프의 예외 주소는 같은 ntdll 오프셋이며, 예외 스레드의 스택 영역에 `quartz.dll` 및 `cv2.pyd` 주소가 확인됐습니다. Qt 메모리 오류로 단정하지 않았으며, 원본 덤프는 로컬에만 유지합니다.

INFERRED: 화면 전환 시 이전 영상 작업의 종료를 요청한 직후 새 작업이 카메라를 여는 구조가 Windows 영상 그래프 정리와 충돌했을 가능성이 있습니다. 네이티브 전체 심볼 스택을 복원한 것은 아니므로 덤프만으로 단일 원인을 확정하지 않습니다.

- EXTRACTED: 호버 이벤트 중 창 크기나 화면이 바뀌어 커서 위치가 해제됐을 때, 해제된 위치·위젯을 다시 사용하지 않습니다.
