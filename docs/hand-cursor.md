# 앱 내부 손 커서

EXTRACTED: 메인·설정·게임 종료 결과 화면과 저장된 결과 목록에서 MediaPipe로 앱 내부 포인터를 움직입니다. 운영체제의 실제 마우스 위치를 바꾸거나 전역 마우스 입력을 보내지 않습니다. 기존 마우스와 키보드도 계속 사용할 수 있습니다.

사용법:

- 손가락을 3개 이상 펼치면 손바닥 위치에 따라 초록색 원형 커서가 움직입니다. 손가락 끝 대신 손목과 손바닥 관절 위치를 사용하고 움직임을 평활화합니다.
- 손을 한 번 접으면 해당 위치를 고정하고 클릭을 준비합니다. 원이 노란색으로 바뀌며, 두 번째 접기를 기다리는 450ms 이후 한 번 클릭합니다. 엄지가 약간 펴져 있어도 나머지 네 손가락을 접으면 주먹으로 처리합니다.
- 그 시간 안에 손을 다시 펼쳤다 접으면 첫 클릭을 취소하고 스크롤 모드를 켭니다. 보라색 원과 `SCROLL` 표시가 나타납니다. 손을 아래로 움직이면 아래 내용을, 위로 움직이면 위 내용을 봅니다. 진입 지점을 기준으로 작은 움직임은 무시하고 이동량에 따라 속도가 달라집니다.
- 빠르게 두 번 접으면 스크롤 모드를 해제합니다. 모드 중 한 번 접기는 클릭하지 않습니다. ESC도 모드와 대기 중 클릭을 취소합니다.

EXTRACTED: 스크롤 대상은 커서 아래 목록·스크롤 영역입니다. 아래에 해당 영역이 없으면 화면의 스크롤 가능한 영역을 사용합니다. 설정 드롭다운은 앱이 소유한 팝업의 활성화된 항목만 선택합니다. 펼쳐진 드롭다운 밖을 클릭하면 닫습니다.

EXTRACTED: 게임 플레이와 보정 화면에서는 동작하지 않습니다. 화면 전환, 창 크기 변경, 포커스 이탈, 모달 대화상자, 손 미검출 또는 오래된 인식 결과에서는 동작을 취소합니다. 새 화면에서는 손을 펼친 뒤 접어야 클릭할 수 있습니다. OpenCV 근사 인식은 커서 조작에 사용하지 않습니다.

EXTRACTED: 결과 화면의 `Play Again`과 `Back to Start`, 결과 목록의 기록 선택·스크롤·새로고침·뒤로가기도 손으로 조작합니다. 결과 화면은 메인 창의 영상 세션을 임대하므로 게임→결과→재시작/메인 전환에도 카메라를 추가로 만들지 않습니다. 목록이 비어 있을 때 반복 새로고침해도 빈 상태 라벨을 재사용합니다. `WorkOrder/verify_result_hand_cursor.py`에서 실제 접기 입력과 Qt 버튼 동작, 기록 선택·스크롤 및 단일 카메라 수명을 검증합니다.

EXTRACTED: 기존 영상 작업 스레드의 최신 결과를 공유하므로 커서를 위해 카메라나 MediaPipe 추론을 추가 실행하지 않습니다. 설정 화면 진입 시 카메라 미리보기를 자동 시작합니다. 카메라가 비활성화됐거나 MediaPipe가 준비되지 않았다면 손 조작을 하지 않습니다.

검증: `WorkOrder/verify_hand_cursor.py`에서 단일 클릭, 두 번 접기의 클릭 취소, 스크롤 켜기·끄기와 실제 목록 이동, 드롭다운 선택, 추적·포커스·모달·ESC 차단, 앱 내부 범위, 실제 OS 커서 위치 유지, 화면 전환을 검증합니다. EXE 자체 검사에는 원형 포인터 렌더링과 접기 구분 검사를 포함합니다.

AMBIGUOUS: 실제 카메라 착용 환경에서의 이동 감도와 접기 인식 체감은 현장 확인이 필요합니다.
