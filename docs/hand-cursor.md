# 앱 내부 손 커서

EXTRACTED: 메인·설정·게임 종료 결과 화면과 저장된 결과 목록에서 MediaPipe로 앱 내부 포인터를 움직입니다. 운영체제의 실제 마우스 위치를 바꾸거나 전역 마우스 입력을 보내지 않습니다. 기존 마우스와 키보드도 계속 사용할 수 있습니다.

사용법:

- 손가락을 3개 이상 펼치면 손바닥 위치에 따라 초록색 원형 커서가 움직입니다. 손가락 끝 대신 손목과 손바닥 관절 위치를 사용하고 움직임을 평활화합니다.
- 손을 한 번 접으면 해당 위치를 고정하고 클릭을 준비합니다. 원이 노란색으로 바뀌며, 기존 450ms 확인 지연 후 한 번 클릭합니다. 엄지가 약간 펴져 있어도 나머지 네 손가락을 접으면 주먹으로 처리합니다.
- 손바닥을 카메라로 향하고 팔을 고정한 채 손가락을 정확히 두 개 폅니다. 처음에는 손목을 곧게 유지합니다. 약 0.4초의 안정된 자세를 수집하면 `HOLD WRIST`가 `WRIST READY`로 바뀝니다.
- **두 손가락을 편 상태에서만** 손의 3D 기울기를 검사합니다. 손목을 뒤로 젖히면 `SCROLL UP`으로 위쪽 항목을, 안쪽으로 굽히면 `SCROLL DOWN`으로 아래쪽 항목을 봅니다. 손 전체를 화면 위아래로 옮기는 드래그 방식은 제거했습니다.
- 기울기를 유지하는 동안 계속 스크롤하며, 중립으로 돌아오거나 두 손가락 자세를 풀면 멈춥니다. 스크롤 종료를 주먹 클릭으로 처리하지 않습니다. ESC는 스크롤·대기 클릭과 중립 기준을 초기화하므로 다시 손목을 곧게 유지합니다.
- 중립 대비 약 15도 기울기가 약 90ms 지속되면 진입하고 약 8도 이내로 돌아오면 종료합니다. 방향을 바꾸는 동안에는 멈춘 뒤 새 방향을 확인합니다. 기울기를 확인하기 전까지 대기 클릭을 보류하며, 스크롤이 시작되면 취소합니다.

EXTRACTED: 스크롤 대상은 커서 아래 목록·스크롤 영역입니다. 아래에 해당 영역이 없으면 화면의 스크롤 가능한 영역을 사용합니다. 설정 드롭다운은 앱이 소유한 팝업의 활성화된 항목만 선택합니다. 펼쳐진 드롭다운 밖을 클릭하면 닫습니다.

EXTRACTED: 게임 플레이와 보정 화면에서는 동작하지 않습니다. 화면 전환, 창 크기 변경, 포커스 이탈, 모달 대화상자, 손 미검출 또는 오래된 인식 결과에서는 동작을 취소합니다. 새 화면에서는 손을 펼친 뒤 접어야 클릭할 수 있습니다. OpenCV 근사 인식은 커서 조작에 사용하지 않습니다.

EXTRACTED: 결과 화면의 `Play Again`과 `Back to Start`, 결과 목록의 기록 선택·스크롤·새로고침·뒤로가기도 손으로 조작합니다. 결과 화면은 메인 창의 영상 세션을 임대하므로 게임→결과→재시작/메인 전환에도 카메라를 추가로 만들지 않습니다. 목록이 비어 있을 때 반복 새로고침해도 빈 상태 라벨을 재사용합니다. `WorkOrder/verify_result_hand_cursor.py`에서 실제 접기 입력과 Qt 버튼 동작, 기록 선택·스크롤 및 단일 카메라 수명을 검증합니다.

EXTRACTED: 기존 영상 작업 스레드의 최신 결과를 공유하므로 커서를 위해 카메라나 MediaPipe 추론을 추가 실행하지 않습니다. 설정 화면 진입 시 카메라 미리보기를 자동 시작합니다. 카메라가 비활성화됐거나 MediaPipe가 준비되지 않았다면 손 조작을 하지 않습니다.

EXTRACTED: `WorkOrder/verify_hand_cursor.py`에서 주먹 클릭 유지, 두 손가락 중립 수집, 손목 젖힘/굽힘에 따른 실제 목록 위/아래 이동, 중립 정지, 손 위치 이동만으로 스크롤하지 않음, 자세 해제 오클릭 방지와 기존 포커스/모달/ESC/팝업/화면 범위 검사를 통과했습니다. `verify_result_hand_cursor.py`의 결과·기록 목록 조작도 통과했습니다. `verify_wrist_scroll.py`의 7개 검사는 합성 3D 관절로 상대 기울기·이동/크기 불변·두 손가락 한정·잘못된 깊이 차단·중립 안정화·방향 전환을 검증합니다.

EXTRACTED: 기존 MediaPipe 결과에 `landmarks_3d`를 추가 전달합니다. 모델 실행·손 선택·손가락 개수·게임 레인 계산은 변경하지 않습니다. [MediaPipe 공식 설명](https://github.com/google-ai-edge/mediapipe/blob/master/docs/solutions/hands.md)의 손 관절 z는 손목 기준 깊이이며 작은 값일수록 카메라에 가깝습니다. x/z를 영상 종횡비로 보정하고 손목→손바닥 관절 평균 벡터의 깊이 기울기를 중립과 비교합니다.

INFERRED: 이것은 팔꿈치·전완 방향을 포함한 실제 손목 관절각 측정이 아니라 손의 카메라 기준 기울기 추정입니다. 손바닥을 카메라로 향하고 팔을 고정해야 의도한 손목 동작에 대응합니다. 팔 전체의 앞뒤 기울기나 손등을 카메라로 향하는 자세는 같은 동작으로 해석될 수 있으므로 실제 환경에서 방향·감도를 확인해야 합니다.

AMBIGUOUS: 실제 카메라 착용 환경에서의 이동 감도와 접기 인식 체감은 현장 확인이 필요합니다.
