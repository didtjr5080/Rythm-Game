# 플레이어별 보정값과 상위 모드 해금

EXTRACTED: 이 문서의 프로필 도입 빌드는7이며 최신 이미지 빌드8에도 기능을 유지한다. 현재 실행 파일과 보관 대상 버전은 [배포 안내](windows-release.md)의 최신 항목을 따른다. 아래7/직전6 정리 수치는 당시 기록이다.

EXTRACTED: 2026-11-18 사용자 요청으로 로컬 플레이어 프로필을 추가했다. 이름과 별도 UUID로 사람을 구분하며 핀치 보정·근전도 최저값·기본 두 모드 완료 이력을 각각 저장한다. 메인과 게임 선택의 플레이어 목록 및 '프로필 추가·삭제·보정 관리'에서 조작한다.

## 사용 순서

1. 프로필 관리에서 이름을 입력해 만들거나 기존 사람을 선택한다.
2. 핀치 보정값이 없으면 첫 핀치 시작 때 측정해 저장한다. 있으면 해당 사람의 네 손가락 보정값을 직접 주입하고 보정을 건너뛴다.
3. 근전도 기준이 없으면 첫 근전도 시작 때3.0초 기록의 최저값을 저장한다. 있으면 기록 화면 없이 그 최저값을 즉시 사용한다.
4. 같은 프로필로 기본 핀치·근전도 게임을 각각 정상 완주하면 상위 핀치+신전 카드가 열린다. 이 모드는 이미 저장된 두 보정값으로 바로 시작한다.
5. 재보정하려면 관리 화면에서 해당 보정값을 지운 뒤 기본 모드를 시작한다. 그 모드의 완료 이력도 초기화되어 다시 완주해야 해금된다.

EXTRACTED: 사용자가 정한 성공 기준은 정확도 제한 없이 정상 완주다. 선택 곡은 실제 재생이 정상 종료되고 모든 노트 처리가 끝나야 한다. 곡이 없는 기본 샘플도 정상 끝까지 완료하면 기록한다. ESC·뒤로·창 닫기·재생 오류·연속MISS10 종료는 성공으로 기록하지 않는다. 보정 저장만으로는 성공하지 않는다.

EXTRACTED: 선택한 사람의 핀치와 근전도 완료가 모두 있어야 하며 다른 사람의 완료 이력은 합산하지 않는다. 잠긴 카드를 비활성화하고 게임 시작 함수와 GameWidget 생성 시점에도 확인한다. 프로필 없이 연습은 기본 모드만 가능하며 보정·완료 이력을 저장하거나 상위 모드를 해금하지 않는다.

## 저장과 삭제

EXTRACTED: 파일은 개발 실행의 `app/data/player_profiles.json`, EXE의 `_internal/app/data/player_profiles.json`이다. 기존 이름별 `leap_calibration.json`은 이름과 핀치 보정값만 가져온다. 이력에 프로필 식별자가 없는 과거 결과나 근전도 기준을 임의로 사람에게 연결하지 않는다. 이전 파일은 보존하며, 통합 프로필을 삭제한 뒤에는 다시 자동으로 가져오지 않는다.

EXTRACTED: 선택 시점의 프로필 UUID를 게임에 고정한다. 진행 중 다른 프로필이 선택되더라도 측정·완료 이력은 시작한 사람에게만 저장한다. 삭제된 프로필을 뒤늦은 결과가 다시 만들지 않는다. 완료 기록 저장에 실패하면 결과 화면에 표시하고 해금하지 않는다. 프로필 파일이 손상되면 오류를 표시하며 빈 파일로 덮어쓰지 않는다.

EXTRACTED: 삭제 확인 후 해당 통합 프로필의 보정값·완료 이력을 삭제한다. 기존 결과·세션과 과거 보정 원본·백업은 유지한다. 결과에는 플레이어 이름/UUID·정상 완주 여부·종료 사유·근전도 보정 재사용 여부를 기록한다. 재사용 보정의 측정 목록은 원래 저장된 목록이며 그 게임에서 새로3초 측정했다고 표시하지 않는다.

EXTRACTED: 이름은1~80자, 같은 이름(대소문자 무관)의 중복 생성을 막는다. 저장된 보정값을 검증하고 원자 파일 교체로 저장한다. 핀치 보정값은 전역 활성 이름에 의존하지 않고 해당 사람의 값으로 전달하므로 사람 간 보정이 섞이지 않는다. 프로필·보정 런타임 JSON은 Git과 배포 ZIP에서 제외한다.
