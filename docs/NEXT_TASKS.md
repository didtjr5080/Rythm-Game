## 1. 음악 분석과 실제 재생의 시간축 확인 — 최우선

- [x] 동일 MP3의 분석 길이 208.013초와 soundfile 길이 213.773초 차이를 재현한다.
- [x] 분석에서 실제로 불러온 모듈 경로, 디코더, 샘플레이트·프레임 수를 기록하여 원인을 구분한다.
- [x] 선택 곡·실제 재생 파일·캐시 원본이 동일한지 확인한다. 곡 변경 및 기존 채보 재사용도 확인한다.
- [ ] 곡 시작·중간·끝에서 비트와 노트 기준선 통과 시각을 비교하고, 일정 오프셋인지 누적 오차인지 측정한다.

EXTRACTED: 위 길이 차이와 75개 테스트 통과는 직전 로컬 검증에서 관찰됐다. AMBIGUOUS: 길이 차이의 원인과 체감 동기화 개선 여부는 확정되지 않았다. 읽어 본 legacy 분석 파일에는 명시적 무음 제거가 없으므로 무음 제거를 원인으로 단정하지 않는다.

완료 조건: 같은 원본에서 분석·재생의 시간 기준을 설명할 수 있고, 전체 곡의 시작·중간·끝에 대해 측정한 동기화 결과를 기록한다. 분석·재생 실패 시 다른 곡이나 샘플 노트로 진행하지 않는지도 검증한다. 수정이 필요하면 legacy_web 변경 금지 조건을 지키는 적용 위치부터 검토한다.
